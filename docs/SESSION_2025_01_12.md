## Key Learnings

1. **GCP Authentication**: `gcloud auth application-default login` for local dev
2. **API Enablement**: Must explicitly enable APIs (`aiplatform`, `artifactregistry`)
3. **Filter Syntax**: Vertex AI uses `=` with wildcards, not `~` for contains
4. **Git Basics**: `git remote -v` shows nothing = not a proper repo clone
