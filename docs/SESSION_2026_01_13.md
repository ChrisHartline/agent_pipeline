## Issues Encountered & Fixes

### Issue 1: Cloud Build API Not Enabled
**Error:** `API [cloudbuild.googleapis.com] not enabled`
**Fix:** Type `y` when prompted, or run:
```bash
gcloud services enable cloudbuild.googleapis.com
```

### Issue 2: Permission Denied for Cloud Build
**Error:** `PERMISSION_DENIED: The caller does not have permission`
**Fix:** Grant Cloud Build permissions:
```bash
gcloud projects add-iam-policy-binding celestinecircle \
  --member="user:chris.hartline.99@gmail.com" \
  --role="roles/cloudbuild.builds.editor"

gcloud projects add-iam-policy-binding celestinecircle \
  --member="serviceAccount:552908345071@cloudbuild.gserviceaccount.com" \
  --role="roles/artifactregistry.writer"
```

### Issue 3: Invalid Image Name (Empty Tag)
**Error:** `invalid image name "...:": could not parse reference`
**Cause:** `${SHORT_SHA}` variable is only available in git-triggered builds, not manual `gcloud builds submit`
**Fix:** Changed `cloudbuild.yaml` to use `_TAG: latest` substitution instead of `${SHORT_SHA}`

### Issue 4: Missing Staging Bucket
**Error:** `staging_bucket should be set in TrainingJob constructor`
**Cause:** Vertex AI SDK requires a staging bucket for temporary files
**Fix:** Added `staging_bucket` to `aiplatform.init()`:
```python
aiplatform.init(
    project=PROJECT_ID,
    location=REGION,
    staging_bucket=f"gs://{MODELS_BUCKET}",
)
```

### Issue 5: Model Serving Container Required
**Error:** `model_serving_container_image_uri was not provided`
**Cause:** `CustomContainerTrainingJob` expects both training AND serving containers
**Fix:** Switched to `CustomJob` which is training-only (no model registration)

### Issue 6: Async Job Resource Name Not Available
**Error:** `CustomJob resource has not been created` when accessing `job.resource_name`
**Cause:** With `sync=False`, the job object doesn't have resource info immediately
**Fix:** Changed to `sync=True` to wait for job completion and see actual errors

### Issue 7: GPU Quota Exceeded
**Error:** `RESOURCE_EXHAUSTED: quota metrics exceed quota limits: custom_model_training_nvidia_t4_gpus`
**Cause:** New GCP projects have 0 GPU quota by default
**Fix:** Switched to CPU-only training by setting:
```python
ACCELERATOR_TYPE = None
ACCELERATOR_COUNT = 0
```

## Key Learnings

| Topic | Learning |
|-------|----------|
| Cloud Build | `SHORT_SHA` only works with git triggers, not manual submits |
| Vertex AI SDK | `CustomJob` = training only; `CustomContainerTrainingJob` = train + deploy |
| Vertex AI SDK | `sync=True` shows real errors; `sync=False` fails silently |
| GCP Quotas | GPU quota starts at 0, must be requested |
| Container vs Script | Changes to `gcp_pipeline/*.py` don't need rebuild; changes to `scripts/*.py` do |
